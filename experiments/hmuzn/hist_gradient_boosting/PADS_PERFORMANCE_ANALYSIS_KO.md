# PADS 전체 데이터 평가와 성능 하락 원인

## 결론

Histogram Gradient Boosting 분류기는 팀의 건강인 모사 떨림 데이터에서는
balanced accuracy 99.17%를 기록했지만, PADS strict 코호트에서는 76.13%를
기록했다. 이는 모델이 망가졌다는 뜻이 아니라, 작고 단순한 모사 데이터에서 얻은
패턴이 더 다양하고 어려운 PADS 데이터에 완전히 일반화되지 않았다는 뜻이다.

현재 결과는 가능성을 확인한 연구용 baseline으로는 의미가 있지만, 실제 순간별
떨림 탐지나 의료 진단에 사용할 수 있는 성능을 입증하지는 않는다.

## 평가 설정

| 항목 | 팀 자체 데이터 | PADS strict 코호트 |
| --- | ---: | ---: |
| 참가자 | 6명 | 160명 |
| recording | 220개 | 1,600개 |
| 양성 라벨 | 건강인의 모사 떨림 | 진단 정보에서 도출한 weak label |
| 센서 환경 | 기존 팀 IMU | 양손목 Apple Watch Series 4 |
| 평가 | LOSO | 참가자 분리 5-fold |
| 입력 | 가속도계+자이로스코프 | 가속도계+자이로스코프 |
| 전처리 | 50 Hz, 3초 window | 50 Hz, 3초 window |

PADS 평가는 weak-label tremor 81명과 healthy 79명을 사용했다. 각 참가자의 모든
recording은 반드시 같은 fold에 배치했고, 두 라벨의 참가자 수를 각 fold에 최대한
균등하게 배분했다. 따라서 같은 사람의 데이터가 train과 test에 동시에 들어가는
participant leakage는 없다.

## 전체 평가 결과

| 지표 | 팀 자체 데이터 | PADS 전체 데이터 |
| --- | ---: | ---: |
| Balanced accuracy | 99.17% | **76.13%** |
| Sensitivity | 98.33% | **71.04%** |
| Specificity | 100.00% | **81.22%** |
| Macro F1 | 99.16% | **75.99%** |
| AUROC | 99.17% | **84.51%** |

PADS의 1,600개 recording을 합치면 confusion matrix는 다음과 같다.

| 실제/예측 | non-tremor 예측 | tremor 예측 |
| --- | ---: | ---: |
| 실제 non-tremor | 642 | 148 |
| 실제 weak-label tremor | 235 | 575 |

일반 accuracy는 `(642 + 575) / 1600 = 76.06%`이다. 두 클래스의 recall을 동일한
비중으로 평가한 fold 평균 balanced accuracy는 76.13%이다.

## 성능이 하락한 이유

### 1. 모사 떨림과 실제 환자 신호의 차이

팀 데이터의 떨림은 건강한 참가자가 의도적으로 재현했다. 이런 움직임은 실제
병적 떨림보다 진폭이 크고 반복 속도가 일정할 수 있어 non-tremor와 쉽게 구분된다.

실제 환자의 떨림은 사람, 자세, 질환 상태와 약 복용 상태에 따라 강도와 주파수가
달라지고, 한 recording 안에서도 간헐적으로 나타날 수 있다. 따라서 자체 데이터에서
효과적이었던 단순한 진폭·주파수 경계가 PADS에서는 충분하지 않을 수 있다.

### 2. 참가자 수와 개인차 증가

자체 데이터는 6명뿐이어서 가능한 손목 움직임과 센서 패턴의 범위가 좁다. 모델이
일반적인 떨림 원리뿐 아니라 특정 참가자의 움직임 크기, 착용 습관 또는 실험 환경을
학습했을 가능성이 있다.

PADS는 160명을 사용하므로 나이, 질환 정도, 손잡이, 손목, 움직임 방식과 신호의
세기가 훨씬 다양하다. 더 현실적인 시험에서 성능이 내려간 것은 기존 99.17%가 실제
일반화 성능을 과대평가했을 가능성을 보여준다.

### 3. 구간별 떨림 정답이 없는 weak label

PADS에는 각 recording 또는 3초 window에서 실제로 떨림이 발생했는지를 나타내는
정답이 없다. 현재 양성 라벨은 참가자의 진단명과 `disease_comment`에서 떨림 관련
표현을 찾아 도출한 사람 단위 weak label이다.

떨림 관련 진단이 있는 사람도 모든 측정 순간에 떨지는 않는다. 실제 신호에 떨림이
없는 구간을 모델이 non-tremor로 판단해도 평가에서는 false negative가 된다. 반대로
건강인의 정상적인 반복 움직임이 tremor 주파수와 비슷하면 false positive가 될 수
있다. 따라서 현재 오차 중 일부는 모델 오류가 아니라 라벨의 시간 해상도 부족에서
발생할 수 있다.

### 4. 센서와 수집 환경의 domain shift

기존 팀 IMU와 PADS의 Apple Watch는 센서 하드웨어, 노이즈, range, 보정 방식과
착용 위치가 다르다. PADS 가속도는 중력이 제거된 user acceleration이며, 기존 원시
데이터의 가속도는 약 1 g의 중력 성분을 포함한다.

현재 특징 추출은 window별 축 평균을 제거하므로 중력 차이를 일부 완화하지만, 센서
노이즈와 스케일 차이를 모두 없애지는 못한다. 특히 모델이 진폭 특징에 의존하면
기기 변경만으로도 예측 경계가 달라질 수 있다.

### 5. 정상적인 큰 움직임이 작은 떨림을 가림

PADS에는 안정 상태뿐 아니라 팔 뻗기, 팔 들기와 무게 들기 과제가 포함된다. 자세를
잡는 과정의 큰 움직임이나 근육 피로로 인한 움직임은 작은 병적 떨림보다 센서에서
더 크게 나타날 수 있다.

모델은 단순히 움직임이 큰지를 판단하는 것이 아니라 정상적인 의도 동작 위에 섞인
작은 반복 성분을 구분해야 한다. 이는 정지 상태에서 의도적으로 떨었던 자체
데이터보다 어려운 문제다.

### 6. 떨림 주파수 분포의 차이

자체 데이터의 모사 떨림과 실제 환자의 떨림은 지배적인 주파수 범위가 다를 수 있다.
현재 B2 특징은 3–12 Hz 전체와 3–6, 6–9, 9–12 Hz 구간을 사용하지만, 학습 데이터의
고주파 모사 떨림에 맞춰진 규칙이 실제 환자의 더 낮고 약한 떨림에 그대로 적용되지
않을 수 있다.

### 7. 하나의 고정 임계값 사용

현재 모델은 tremor 확률이 0.5 이상이면 양성으로 판단한다. 하지만 참가자마다 평소
움직임의 크기와 센서 기준선이 다르기 때문에 모든 사람에게 같은 0.5 임계값이
최적이라고 볼 수 없다.

임계값을 변경하려면 반드시 각 fold의 training/validation 데이터에서만 결정해야
한다. test 데이터를 보고 임계값을 고르면 평가 누수가 발생한다.

### 8. 모델이 시간 순서를 직접 보지 않음

현재 모델은 3초 window의 특징을 계산한 뒤 recording별 median과 IQR로 집계한다.
이 방법은 작고 해석하기 쉽지만, 떨림이 언제 시작되고 멈췄는지 또는 반복 패턴이
시간에 따라 어떻게 변했는지를 직접 학습하지 못한다. 간헐적 떨림은 median 집계에서
약해지거나 사라질 수 있다.

## 결과를 해석할 때 주의할 점

- 76.13%는 임상 진단 정확도가 아니다.
- 76.13%는 순간별 tremor detection 정확도가 아니다.
- PADS 참가자의 진단에서 만든 weak label을 recording마다 부여한 연구용 결과다.
- 자체 데이터의 99.17%와 PADS의 76.13%는 데이터와 라벨 정의가 달라 완전히 같은
  시험으로 볼 수 없다.
- 환자 데이터의 재현율이 71.04%이므로 현재 상태에서는 양성 recording 약 29%를
  놓친다.

## 다음 개선 방향

1. 실제 recording/window별 떨림 annotation이 있는 데이터로 평가한다.
2. 사람·세션별 정규화를 training fold 안에서 적용한다.
3. 안정·자세·무게 들기 과제를 별도로 평가해 동작별 실패 원인을 확인한다.
4. 3–7 Hz 환자 떨림 대역을 중심으로 특징 구성을 다시 비교한다.
5. threshold는 training fold 내부 validation으로만 선택한다.
6. window 예측을 유지한 뒤 연속된 양성 window를 결합해 간헐적 떨림을 찾는다.
7. 가속도계·자이로스코프 raw sequence를 사용하는 작은 1D CNN과 비교한다.
8. 최종 평가는 학습과 모델 선택에 사용하지 않은 별도 참가자에서 수행한다.

## 최종 판단

현재 분류기는 무작위 기준인 50%보다 확실히 높고 AUROC도 84.51%여서 떨림 관련
신호를 어느 정도 구분하는 능력은 있다. 따라서 연구용 baseline으로는 유효하다.
그러나 sensitivity가 71.04%이고 라벨도 사람 단위 weak label이므로 실제 사용 또는
의료적 판단에 적용할 수준은 아니다.

가장 정확한 표현은 다음과 같다.

> Histogram Gradient Boosting 모델은 건강인의 모사 떨림에는 높은 성능을 보였지만,
> 실제 환자와 다양한 동작을 포함한 PADS에서는 balanced accuracy 76.13%로 감소했다.
> 이는 데이터 및 센서 환경의 차이, 개인차, 구간별 정답 부재와 모델의 제한된 시간
> 표현 때문에 발생한 것으로 보이며, 현재 모델은 연구용 프로토타입이다.
